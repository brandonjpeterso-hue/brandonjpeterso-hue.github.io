How this is calculated

Projections use a constant monthly rate i = annual return / 12 and end-of-month deposits: FV = PV × (1 + i)ᵗ + PMT × [((1 + i)ᵗ − 1) / i]. Returns are assumed constant and fee-free. This is an estimate, not a forecast.
